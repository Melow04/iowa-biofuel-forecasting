# Data

The dataset is **Iowa Motor Fuel Sales by County and Year**, published by the Iowa Department of Revenue on data.iowa.gov:

https://data.iowa.gov/Sales-Distribution/Iowa-Motor-Fuel-Sales-by-County-and-Year/hbwp-wys3/about_data

1. Download the data as CSV (Export, then CSV).
2. Save it in this folder as `Iowa_Motor_Fuel_Sales_by_County_and_Year.csv`.
3. Run the notebook in `notebooks/`.

The file is a public government dataset. Counties with five or fewer retail locations are reported together as "Other" between 2011 and 2020 for confidentiality.
